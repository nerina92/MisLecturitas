# MisLecturitas

MisLecturitas es una aplicación que funciona como biblioteca digital para los mas pequeños con algunos juegos que acompañan la didactica de la lectura. 

## Descripción

- Objetivo: Proveer una plataforma ligera para almacenar, categorizar y recomendar lecturas cortas. Con juegos adecuados a las edades de los niños.
- Público objetivo: lectores que buscan lecturas rápidas y creadores que quieran compartir fragmentos o cuentos cortos.

## Características

- Añadir, editar y eliminar lecturas.
- Organización por categorías y etiquetas.
- Búsqueda y filtrado por título, autor y etiquetas.
- Sistema de recomendaciones simples (p. ej. por etiquetas similares).

## Tecnologías (indica la pila real del proyecto)

- Desarrollo: Kotlin en Android Studio con Jetpack compose
- Base de datos: Realtime Database - Firebase
