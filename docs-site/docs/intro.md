# Introducción

Bienvenido a la documentación de **Mis Lecturitas** 📚

## ¿Qué es Mis Lecturitas?

**Mis Lecturitas** es una aplicación móvil educativa diseñada para ayudar a niños a aprender a leer de manera interactiva y divertida. La aplicación ofrece:

- 📖 **Biblioteca de libros digitales** organizados por niveles de dificultad
- 🎧 **Audiolibros** con narraciones profesionales
- 👨‍🏫 **Panel de administración** para docentes
- 🔐 **Sistema de autenticación** seguro con Firebase
- 📱 **Interfaz intuitiva** diseñada para niños

## Características principales

### Para estudiantes
- Acceso a libros digitales con ilustraciones
- Reproducción de audiolibros
- Navegación por niveles de dificultad
- Interfaz amigable y colorida

### Para administradores
- Gestión de contenido (libros y audiolibros)
- Publicación de nuevo material educativo
- Control de usuarios
- Administración de niveles

## Tecnología

La aplicación está desarrollada con tecnologías modernas:

- **Lenguaje**: Kotlin
- **Framework UI**: Jetpack Compose
- **Backend**: Firebase (Realtime Database, Authentication, Storage)
- **Arquitectura**: MVVM (Model-View-ViewModel)
- **Gestión de dependencias**: Koin
- **Carga de imágenes**: Coil

## Versión actual

- **Versión**: 2.1
- **Código de versión**: 3
- **SDK mínimo**: Android 6.0 (API 23)
- **SDK objetivo**: Android 15 (API 35)
